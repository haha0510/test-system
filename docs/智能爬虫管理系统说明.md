# 智能爬虫管理系统说明文档

## 一、功能概述

本系统实现了智能化的爬虫管理功能，能够根据用户提供的URL和Request Headers自动分析生成爬虫配置，满足商业化软件的使用要求。

### 核心特性

1. **智能分析**：根据源地址+Headers包自动推断爬虫规则
2. **动态执行**：无需编写代码，配置即爬虫
3. **可视化操作**：提供友好的Web界面管理爬虫
4. **数据统计**：实时统计采集成功率、失败原因

## 二、架构设计

### 1. 数据模型优化

**CrawlerConfig** 新字段：

```python
crawler_type: str  # 爬虫引擎类型(html_parser/json_api/jsonp_api)
request_method: str  # 请求方法(GET/POST)
search_params_template: text  # 搜索参数模板(JSON)
pagination_config: text  # 分页配置(JSON)
parse_config: text  # 解析配置(JSON)
analyzed_config: text  # 智能分析结果缓存
is_analyzed: bool  # 是否已完成分析
is_template: bool  # 是否为模板
page_size: int  # 每页数据量
last_error: text  # 最后错误信息
```

**字段分类**：

- **固定配置**：crawler_type、parse_config（爬虫核心模板）
- **动态规则**：search_params_template、pagination_config（运行时参数）
- **状态管理**：is_analyzed、is_template、status
- **统计信息**：success_count、fail_count、last_error

### 2. 核心模块

#### 智能分析器 (`crawler_analyzer.py`)

功能：根据URL和Headers智能推测爬虫配置

```python
analyzer = CrawlerAnalyzer()
result = analyzer.analyze(
    url='https://www.baidu.com/s?tn=news&word={keyword}&pn={offset}',
    request_headers='{"User-Agent": "Mozilla/5.0..."}'
)
```

识别逻辑：

1. **站点识别**：匹配已知模板（百度、360、新华网等）
2. **参数分析**：从QueryString提取搜索参数
3. **Headers提取**：解析User-Agent、Referer等关键头
4. **选择器推断**：根据HTML结构推断解析规则

#### 动态爬虫引擎 (`crawler_dynamic.py`)

功能：根据配置动态执行数据采集

```python
engine = DynamicCrawlerEngine(crawler_config)
results = engine.search_batch("人工智能", count=30)
```

执行流程：

1. 参数模板替换（{keyword}、{page}、{offset}等）
2. 发送HTTP请求（自动处理GET/POST）
3. 根据crawler_type选择解析方式：
   - HTML → BeautifulSoup选择器提取
   - JSON → 路径提取（data.list[0].title）
   - JSONP → 去除包装后JSON解析
4. 智能分页（根据pagination_config自动翻页）

## 六、技术要点

### 1. 变量模板系统

支持以下变量：

- `{keyword}`: 搜索关键词
- `{page}`: 页码（从1开始）
- `{offset}`: 偏移量（从0开始）
- `{count}`: 每页数量
- `{start}`: 起始位置

示例：
```
百度: https://www.baidu.com/s?word={keyword}&pn={offset}
360: https://news.so.com/ns?q={keyword}&pn={page}
```

### 2. 解析配置

**HTML解析**：
```json
{
  "container_selector": "div.c-container",
  "field_selectors": {
    "title": ["h3 a", "title"],
    "url": ["h3 a@href", "url"],
    "summary": ["[class*='content']", "summary"],
    "cover": ["img@src", "cover"],
    "source": ["[class*='source']", "source"]
  }
}
```

**JSON解析**：
```json
{
  "data_path": "data.list",
  "field_paths": {
    "title": "Title",
    "url": "LinkUrl",
    "summary": "Abstract",
    "cover": "allPics[0]",
    "source": "SourceName"
  }
}
```

### 3. 分页类型

**页码型**（page_number）：
```json
{
  "type": "page_number",
  "param": "page",
  "start": 1,
  "step": 1
}
```

**偏移型**（offset）：
```json
{
  "type": "offset",
  "param": "pn",
  "start": 0,
  "step": 10
}
```

## 十、常见问题

### Q1: 置信度是什么意思？
A: 置信度0-100%，表示系统对分析结果的确信程度。90%+表示匹配到已知模板，50%左右为通用分析。

### Q2: 为什么采集不到数据？
A: 可能原因：
- URL模板不正确（变量格式错误）
- Headers缺少必要字段（如Referer）
- 选择器配置错误（页面结构变化）
- 被目标网站限制（需要增加delay）

### Q3: 如何优化爬虫？
A: 建议步骤：
1. 查看测试返回的样本数据
2. 检查last_error错误信息
3. 手动访问URL验证可访问性
4. 调整选择器或参数模板
5. 增加request_delay避免被封

### Q4: 动态爬虫和原有爬虫的区别？
A:
- 动态爬虫：基于配置执行，无需编写Python代码
- 原有爬虫：需要实现具体的Crawler类
- 动态爬虫更灵活，适合快速接入新源
- 原有爬虫性能更好，适合复杂逻辑
