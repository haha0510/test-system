## 🎨 名称解读

### 【舆情雷达】

```
舆情：明确系统处理的数据类型
  ├─ 舆论观点
  ├─ 公众意见
  └─ 社会反应

雷达：隐喻系统的核心特性
  ├─ 实时监测 - 像雷达一样持续扫描
  ├─ 早期预警 - 提前发现问题
  └─ 精准定位 - 准确定位舆情热点
```

### SENTIMENT • ANALYSIS • MONITORING • INTELLIGENCE

```
数据流向链：
  数据(SENTIMENT) → 分析(ANALYSIS) → 监测(MONITORING) → 情报(INTELLIGENCE)

功能对标：
  ✓ SENTIMENT  = 舆情数据采集
  ✓ ANALYSIS   = 智能分析处理
  ✓ MONITORING = 实时监测预警
  ✓ INTELLIGENCE = 输出决策情报
```
